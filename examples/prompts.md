# 提问模板库 · Prompt Cookbook

> **不会写提示词？直接复制下面的句子。**
> 每一条都已对应到某个技能，说人话就能用。
>
> 💡 **建议从「🧠 记忆」开始**——它是这个仓库的核心，也是唯一会越用越值钱的部分。

---

## 🧠 记忆（核心 —— 建议先用起来）

| 复制这句话 | 命中技能 | 你会得到 |
|---|---|---|
| 记一下我这次的操作 | `trade-journal` | 结构化落账：决策/理由/预期/验证期 |
| 帮我记住这个判断 | `trade-journal` | 同上（越记越准） |
| 回顾一下我这段时间的操作 | `review-loop` | 待验证决策清单 + 对照实际 + 命中率 |
| 我上次的判断对了吗？ | `review-loop` | 逐条回填真实结果，提炼教训 |
| 我以前遇到过类似情况吗？ | `similar-cases` | 历史相似情境的判断与结果对照 |
| 历史上这种情况我怎么处理的？ | `similar-cases` | 你的私人经验检索 |
| 如果当时没卖会怎样？ | `what-if` | 反事实对比（基于历史实证） |
| 这两个方案哪个好？ | `what-if` | 两个选项的历史结果对比 |
| 我的记忆库怎么样？ | `memory-health` | 记忆库健康报告 |
| 我的预测准吗？ | `memory-health` | 预测校准报告（历史命中率） |

> 这五个技能是**入口**：先记账（trade-journal），再定期回顾（review-loop），其余所有分析技能都会自动带上"历史参照"。

## 💡 提问技巧（可选读）

1. **带上标的和数据**：技能需要 K 线数据，数据越全结果越准（如"用最近 250 天日线"）
2. **想快就说"大致"**：轻问只跑 1-2 个工具，几秒出结果；说"算不算显著/稳不稳"会触发深问（更慢更准）
3. **要报告就说"详细"**：如"给我一份详细的持仓体检"
4. **重任务用异步**：回测/训练类会说"已提交，job_id=xxx"，之后问"任务跑完了吗"即可

## ⚠️ 边界

技能输出的是**统计计算结果**（CAR、p 值、IC、权重、预测分），**不是买卖建议**。
任何决策请自行判断，并遵守所在地区法律法规。
